# Personal Portfolio Website — Practice Project

Welcome to my portfolio practice repository! This project was built to experiment with web design concepts, practice responsive layouts, and create a visually striking interface for showcasing web projects.

---

## ✨ Features

* 🌓 **Dynamic Theme Toggle:** Smooth transition between Dark & Light mode using Local Storage to remember user preference.
* 📱 **Responsive Design:** Built with Bootstrap 5 to test and optimize cross-device compatibility.
* 📁 **Project Cards:** Practice layout featuring interactive hover animations to display project showcases.
* 🧭 **Interactive UI:** Smooth scrolling, structured timeline sections, and dynamic layout components.
* 📄 **CV Integration:** Styled action button for viewing and downloading a resume.
