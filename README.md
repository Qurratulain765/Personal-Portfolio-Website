# Personal Portfolio Website

Welcome to my Personal Portfolio repository! This project was developed as a task during my **CodeAlpha Web Development Internship**. It is a modern, responsive, and visually striking portfolio website designed to showcase my skills, projects, and professional journey as a web developer[cite: 1].

---

## ✨ Features

* 🌓 **Dynamic Theme Toggle:** Features a smooth, interactive transition between Dark Mode and Light Mode, which saves the user's preference using local storage[cite: 2].
* 📱 **Fully Responsive Design:** Built using Bootstrap 5, ensuring the layout adapts seamlessly across desktops, tablets, and mobile devices[cite: 1].
* 📁 **Project Showcase:** Highlights diverse front-end projects including ECOMIND, GlamCare, Glamous, NestQuest, and Speedy Car with interactive hover animations[cite: 1, 3].
* 🧭 **Smooth Navigation & UI:** Implements fluid scrolling, structured timelines for my educational journey, and a neat skills representation[cite: 1, 3].
* 📄 **CV Integration:** Includes a dedicated, styled button to seamlessly open my professional resume[cite: 1, 2].
